YT-Condense bookmarklet

This page builds a bookmark on your computer. It does not send the address or the secret anywhere.

Enter the worker address and secret. Then drag the link to the bookmarks bar.

YT Condense

Use it

  1. Drag YT Condense to the bookmarks bar after both fields are filled in.
  2. Open a YouTube video that shows a transcript panel.
  3. Click the bookmark. The condensed text is copied to the clipboard.

The bookmarklet reads the transcript panel on the page. If a video has no transcript panel, it tells you the command to run instead: uv run yt_condense.py "URL".
